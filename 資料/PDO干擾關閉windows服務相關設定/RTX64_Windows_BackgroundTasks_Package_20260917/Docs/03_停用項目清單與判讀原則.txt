判讀原則
========

Windows / Master-NAL 類：
- ReceivePacket 可能出現 190~225 us 長尾
- ESC Physical Delta = 0
- Windows Task / Maintenance / VSS 等活動與事件時間可能高度相關

EtherCAT Physical 類：
- ReceivePacket 本身很快
- ESC Physical / Invalid / Forwarded / LostLink Delta 增加
- 優先查線材、接頭、PHY、Slave ingress domain、EMI、PE/ground

兩類問題可能同時存在，不能混為同一根因。
